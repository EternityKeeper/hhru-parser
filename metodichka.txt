Вариант 1. Система двухфакторной аутентификации (2FA) с поддержкой 
TOTP и push-уведомлений 
 Предметная область: Аутентификация и управление доступом 
 Технологии: Python + FastAPI + Redis + Firebase Cloud Messaging 
 Описание: Сервис для обеспечения двухфакторной аутентификации в 
веб-приложениях. Генерация TOTP-кодов (RFC 6238), отправка push-
уведомлений на мобильное приложение. API для интеграции с 
существующими 
системами.

для

Вариант 2. Инструмент статического анализа кода (SAST) для поиска 
уязвимостей типа injection 
 Предметная область: Безопасная разработка 
 Технологии: Python + tree-sitter + Rust 
 Описание: Создание статического анализатора для обнаружения SQL-
инъекций, XSS и Command Injection в коде на Python и Go. 
Использование библиотеки tree-sitter для построения AST, анализ 
потоков данных, выявление небезопасных вызовов. Интеграция с 
CI/CD (GitHub Actions) и генерация отчётов.

микросервис для обработки платежей и эскароу-счетов, Python-бэкенд 
для управления заказами и пользователями. Симуляция блокчейн-
логики для прозрачности. 
Вариант 33. Платформа для онлайн-курсов с видео-стримингом 
 Предметная область: Образование 
 Технологии: Go + Python + Nginx 
 Описание: Go-сервис для стриминга видео с адаптивным битрейтом 
(HLS), Python-бэкенд (Django) для управления курсами, 
пользователями, тестами. Интеграция с CDN, защита контента [ЛР 
№11]. 
Вариант 34. Система логирования и мониторинга микросервисов 
 Предметная область: DevOps, наблюдаемость 
 Технологии: Rust + Go + ELK 
 Описание: Rust-агент для сбора логов с минимальным потреблением 
ресурсов, Go-агрегатор для обработки и записи в Elasticsearch. Веб-
интерфейс для поиска и визуализации, алерты при аномалиях [ЛР 
№11]. 
Категория: Системное программирование и производительность  
Вариант 35. Высокопроизводительная библиотека для линейной 
алгебры 
 Предметная область: Научные вычисления 
 Технологии: C++20 + Python + pybind11 
 Описание: Реализация базовых операций линейной алгебры 
(умножение матриц, обращение, разложение) с использованием SIMD-
инструкций (AVX2/AVX-512). Python-биндинги для использования из 
NumPy-подобного API. Сравнение производительности с OpenBLAS 
[ЛР №9]. 
Вариант 36. Эмулятор CHIP-8 на Rust с WebAssembly 

---
 Предметная область: Эмуляция, ретрогейминг 
 Технологии: Rust + WebAssembly + JavaScript 
 Описание: Эмулятор классического CHIP-8, скомпилированный в 
WebAssembly для запуска в браузере. Поддержка ROM-файлов, 
отображение графики, эмуляция звука. Веб-интерфейс с кнопками 
управления  
Вариант 37. Собственная in-memory база данных "ключ-значение" 
 Предметная область: Базы данных 
 Технологии: C++17 + Boost + gRPC 
 Описание: Реализация ACID-совместимой in-memory БД с 
поддержкой транзакций, персистентностью (snapshot + WAL), сетевым 
доступом через gRPC. Поддержка простых запросов и TTL  
Вариант 38. HTTP/1.1 сервер с нуля на C 
 Предметная область: Сетевое программирование 
 Технологии: C + sockets + epoll 
 Описание: Реализация полноценного HTTP/1.1 сервера с поддержкой 
keep-alive, виртуальных хостов, статических файлов. Неблокирующий 
ввод-вывод (epoll). Сравнение производительности с nginx  
Вариант 39. Компилятор для учебного языка программирования 
 Предметная область: Теория компиляции 
 Технологии: C++ + LLVM + Flex/Bison 
 Описание: Разработка компилятора для простого императивного 
языка. Лексический и синтаксический анализ (Flex/Bison), генерация 
кода через LLVM, поддержка базовых типов, функций, условных 
операторов и циклов  
Вариант 40. Парсер JSON с нуля на Rust 
 Предметная область: Системное программирование 
 Технологии: Rust + Serde-like API 
 Описание: Реализация высокопроизводительного парсера JSON с 
поддержкой полной спецификации. Безопасная работа с памятью (no 
panics), zero-copy parsing для строк. API, совместимое с Serde  
Вариант 41. Распределённая система обмена сообщениями (Message 
Broker) 
 Предметная область: Интеграция систем 
 Технологии: Go + NATS + gRPC 

---
 Описание: Упрощённый аналог RabbitMQ/NATS. Поддержка 
очередей, публикации/подписки, гарантий доставки (at-least-once). Go-
клиенты на gRPC, веб-интерфейс для мониторинга [ЛР №13]. 
Вариант 42. Трассировщик лучей в реальном времени 
 Предметная область: Компьютерная графика 
 Технологии: C++ + Vulkan/Optix + CUDA 
 Описание: Программа для рендеринга трёхмерных сцен с 
использованием аппаратного трассировки лучей (RTX). Поддержка 
материалов, освещения, теней. Интерактивное изменение камеры и 
параметров сцены  
Категория: Мобильные и десктопные приложения  
Вариант 43. Приложение для управления личными финансами 
 Предметная область: Персональные финансы 
 Технологии: Python + Kivy + SQLite 
 Описание: Кроссплатформенное мобильное приложение для учёта 
доходов/расходов. Категоризация транзакций, визуализация 
(диаграммы), финансовые цели, напоминания о платежах. Защита 
данных (шифрование локальной БД)  
Вариант 44. Фитнес-трекер с интеграцией датчиков устройства 
 Предметная область: Здоровье, спорт 
 Технологии: Python + Kivy + Health API 
 Описание: Мобильное приложение для мониторинга физической 
активности: подсчёт шагов, дистанции, калорий. Интеграция с Google 
Fit/Apple Health, графики прогресса, push-уведомления о достижении 
целей  
Вариант 45. Картотека книжной библиотеки с OCR-распознаванием 
 Предметная область: Библиотечное дело 
 Технологии: Python + Tesseract + PyQt5 
 Описание: Десктопное приложение для каталогизации книг. Функция 
распознавания текста с титульного листа (OCR) для автоматического 
заполнения полей (автор, название, издательство). Поиск по каталогу, 
генерация QR-кодов для книг  
Вариант 46. 3D-редактор для параметрического размещения объектов 
 Предметная область: 3D-моделирование 
 Технологии: Python + Blender API + NumPy 

---
 Описание: Модуль-расширение для Blender, реализующий 
параметрическое размещение геометрических объектов в заданном 
пространстве (аналог Corona Scatter). Управление плотностью, 
масштабом, поворотом на основе карт текстур  
Категория: Мультиагентные системы и ИИ  
Вариант 47. Мультиагентная система для автоматизации техподдержки 
 Предметная область: Сервисное обслуживание 
 Технологии: Go + Python + LangChain 
 Описание: Система агентов для обработки тикетов техподдержки. 
Агенты: классификатор (определяет категорию), анализатор (извлекает 
ключевые данные), генератор ответов (LLM), маршрутизатор 
(назначает ответственного). Оркестратор на Python управляет очередью 
[ЛР №13]. 
Вариант 48. Интеллектуальные агенты для игры в жанре "гонки на 
самолётах" 
 Предметная область: Компьютерные игры, ИИ 
 Технологии: C++ + Unreal Engine + Python 
 Описание: Разработка агентов (ботов) для гоночной игры. 
Использование методов reinforcement learning для обучения 
управлению. Python для тренировки моделей, C++ для интеграции с 
игровым движком  
Вариант 49. Распределённая система сбора и анализа данных с IoT-
устройств 
 Предметная область: Интернет вещей (IoT) 
 Технологии: Rust + Go + MQTT 
 Описание: Rust-агенты на устройствах (экономичные, безопасные), 
Go-шлюзы для сбора данных, Python-аналитик для обнаружения 
аномалий и прогнозирования состояния оборудования. Дашборд в 
реальном времени [ЛР №14]. 
Вариант 50. AI-ассистент для разработчика с интеграцией в IDE 
 Предметная область: Инструменты разработчика 
 Технологии: Python + FastAPI + LSP 
 Описание: Сервис, предоставляющий подсказки по коду, генерацию 
тестов и документации через LLM. Интеграция с VS Code через 
Language Server Protocol (LSP). Локальный запуск моделей (Ollama) для 
конфиденциальности [ЛР №12].

Курсовая работа (проект) по дисциплине «Методы и технологии 
программирования» является итоговой работой, демонстрирующей владение 
современными языками программирования (Python, C++, Go, Rust), 
инструментами и методологиями разработки. Успешное выполнение проекта 

---
позволяет не только получить высокую оценку, но и сформировать 
портфолио из реального программного продукта, что является конкурентным 
преимуществом при трудоустройстве

полученных в ходе лабораторных работ №1-16, включая:

 Объектно-ориентированное и функциональное программирование [ЛР 
№3-4] 
 Веб-разработку и базы данных [ЛР №6-7] 
 Мультиязычную разработку (Go, Rust) [ЛР №9-10] 
 Контейнеризацию [ЛР №11] 
 AI-ассистированную разработку [ЛР №12] 
 Мультиагентные системы [ЛР №13]
